DiffusionLight source attribution
================================

scripts/diffusion_engine.py adapts the mirror-ball inpainting/LoRA schedule and
exposure-bracket merge from the official DiffusionLight-Turbo projects:

https://github.com/DiffusionLight/DiffusionLight-Turbo-diffusers
https://github.com/DiffusionLight/DiffusionLight-Turbo

Reference files: inpaint.py, ball2envmap.py, exposure2hdr.py.
Local adaptation: generic image anchor, Apple MPS/CPU support, local-only model
loading, progress callbacks, pinned model checks, direction extraction, and
an explicitly approximate single-exposure fast mode.

Model weights (downloaded separately, not included with this skill)
================================================================

Model weights retain their own licenses and use restrictions. The MIT source
license above does not replace those licenses. The optional downloader uses the
official huggingface_hub SDK to fetch all 25 required files from six repositories
at fixed commit revisions. Files are checked against pinned sizes and hashes:
SHA256 for model weights and Git blob SHA1 for small configuration/tokenizer files.
Existing valid components are reused from the standard or user-selected Hugging
Face cache. Model weights are not redistributed in this skill package.
See references/diffusion.md for setup, model sources and validation limits.
