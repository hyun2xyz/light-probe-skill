# 객체와 다중 반사 입력

객체 윤곽·분류, 재질별 반사율, 여러 번의 반사·산란을 요청받았을 때 읽는다.

## 장면 판독

LLM이 입력 이미지를 보고 객체 이름과 보이는 윤곽을 근사 폴리곤으로 정한다.
기본 표시는 로토스코핑처럼 옅은 저채도 색 마스크와 얇은 윤곽선이다. 원본 사진의 색은 유지한다.
현재 기본 경로는 YOLO/SAM 모델을 실행하지 않는다. 모델 기반 분할 결과로 설명하지 않는다.
검출 확률을 만들어 넣지 말고 `source: "llm_visual"`을 기록한다.
반사율은 밝은 픽셀값과 같지 않다. 광원 세기·노출·표면 방향을 모르므로 사진만으로 실측하지 않는다.
재질명도 시각적 가정일 수 있다. 아래 반사율은 예시 입력이며 보편적인 물성표가 아니다.

## context.json 확장

기존 `scene`, `target`, `light_interpretation`, `assumptions` 외에 다음 필드를 사용한다.

```json
{
  "objects": [
    {
      "id": "bed",
      "label": "침대·침구",
      "material": "직물",
      "bbox": [0.01, 0.52, 0.99, 0.99],
      "polygon": [[0.01, 0.52], [0.38, 0.58], [0.65, 0.62], [0.99, 0.67], [0.99, 0.99], [0.01, 0.99]],
      "color": [173, 161, 185],
      "opacity": 0.18,
      "reflectance": [0.35, 0.65],
      "specular_fraction": 0.06,
      "label_position": "bottom-left",
      "source": "llm_visual"
    }
  ],
  "surfaces": [
    {"id": "bed_plane", "object_id": "bed", "a": [0.1, 0.65], "b": [0.97, 0.65]}
  ],
  "scattering": {"initial_surface_id": "bed_plane", "max_bounces": 3}
}
```

- 박스는 `[x0,y0,x1,y1]`이며 라벨 배치에만 사용한다. 사각 테두리는 그리지 않는다.
- `polygon`은 순서대로 이어지는 `[x,y]` 점 3–128개다. 좌표는 모두 0–1로 정규화하고 마지막 점은 자동으로 닫힌다. 자기 교차 없는 실제 윤곽을 지정한다.
- 객체는 뒤에서 앞으로 정렬한다. 앞 객체가 가린 부분은 뒤 객체 마스크에서 빼므로 색이 중첩되지 않는다.
- `color`는 선택 RGB 정수 배열이다. 채도 낮은 색을 사용하며 생략하면 기본 팔레트를 사용한다.
- `opacity`는 0–0.4 사이이며 기본 0.18이다. 0.16–0.22 정도의 옅은 채움을 유지한다.
- 윤곽이 없는 객체는 라벨만 표시하며 박스를 가짜 분할 마스크로 채우지 않는다. `result.json`의 `object_overlay`에 윤곽 출처와 미표시 객체를 기록한다.
- `reflectance`는 총 반사 에너지 비율의 가정 범위다. 경로 계산에는 중간값을 사용한다.
- `specular_fraction`은 반사 에너지 중 정반사 몫이며 0–1 범위다. 나머지는 확산 반사로 분배한다.
- `label_position`은 top-left, top-right, bottom-left, bottom-right 중 선택한다.
- 객체는 최대 20개지만 보통 3–6개만 골라 라벨·광선을 읽기 쉽게 만든다.
- `surfaces`는 사진에서 복원한 실제 3D 표면이 아니라 별도로 지정한 2D 설명용 선분이다.
- 기준점 `--anchor`가 `initial_surface_id` 선분 위에 있어야 한다.
- 다른 표면으로 진행하는 광선은 가장 가까운 선분 교차에서 멈추고 다음 반사를 계산한다.
- 표면은 실제 객체를 가리키며 객체 박스나 폴리곤을 충돌 형상으로 자동 전환하지 않는다.
- 재질 가정이나 반사율 근거가 불명확하면 수치를 실측·확정된 특성으로 말하지 않는다.

## 계산과 표시의 범위

주광이 지정한 첫 표면에 도달했다고 가정한 뒤 시작한다.
각 충돌에서 입사 에너지에 반사율을 곱하고, 정반사 한 방향과 코사인 가중 확산 방향에 나눈다.
깊이는 최대 3회, 각 충돌에서 후속 충돌 가지는 최대 2개로 제한한다.
따라가지 않은 가지의 에너지는 JSON 기록에 남기고 다음 표면에 임의로 더하지 않는다.
이미지에는 읽기 쉬운 일부 광선만 표시한다. B1/B2/B3은 표면 상호작용 단계다.
현재 경로는 2D 설명용이며 정확한 글로벌 일루미네이션, 시간·장소 기반 태양 위치,
투명체 내부 다중 굴절, 실제 그림자·색 번짐의 재렌더링을 계산한 것으로 설명하지 않는다.

디자인만 수정할 때는 기존 `result.json`과 새 `--context`로 `render`를 호출한다.
